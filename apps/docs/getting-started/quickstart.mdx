---

This guide takes you from an empty dashboard to live traffic, request logs, and traces. It uses FastAPI as the example — the flow is identical for every framework, only the two middleware lines differ.

<Steps>
  <Step title="Create a project">
    Sign in at [app.apilens.ai](https://app.apilens.ai) and create a project. A project groups all the services (apps) that belong to one product, so you can monitor them together.

    <Frame caption="A project with one app per microservice">
      <img src="/images/apps.png" alt="Apps page listing services in a project" />
    </Frame>
  </Step>
  <Step title="Add an app">
    Inside the project, click **Create App** and pick your framework. Each app represents one deployable service — `orders-api`, `payment-service`, and so on. The app's slug becomes the `app_id` you pass to the SDK.
  </Step>
  <Step title="Create an API key">
    Go to **Settings → API keys** and create a key. Copy it now — the full key is shown only once.

    <Note>
    API keys are **project-level**: one key authenticates every app in the project. The SDK's `app_id` tells APILens which app the traffic belongs to.
    </Note>
  </Step>
  <Step title="Install the SDK">
    ```bash
    pip install "apilenss[fastapi]"
    ```

    <Warning>
    The PyPI distribution is `apilenss` (double *s*); the import package is `apilens`.
    </Warning>
  </Step>
  <Step title="Add the middleware">
    ```python
    from fastapi import FastAPI
    from apilens.fastapi import ApiLensMiddleware

    app = FastAPI()
    app.add_middleware(
        ApiLensMiddleware,
        api_key="apilens_xxx",       # better: os.environ["APILENS_API_KEY"]
        app_id="orders-api",
        env="development",           # defaults to "production"
    )
    ```
  </Step>
  <Step title="Send a few requests">
    Run your service and hit any endpoint a couple of times:

    ```bash
    curl http://localhost:8000/orders
    ```

    The SDK batches telemetry in a background thread and flushes every 3 seconds, so data shows up on the **Traffic** page almost immediately. Endpoints are discovered automatically from traffic — there is nothing to pre-register.
  </Step>
</Steps>

## What you get out of the box

With just the middleware in place, every request is captured with method, templated path, status code, response time, payload sizes, and a trace ID. Unhandled exceptions and 5xx responses automatically attach a stack trace you can read in the request's **Trace** tab.

Two things need a line or two more from you:

- **[Consumer identification](/sdk-reference/consumers)** — tell APILens who is calling, to unlock the Consumers page.
- **[Capture tuning](/getting-started/data-privacy)** — bodies and headers are captured by default (with sensitive headers redacted); redact individual fields by name (`redact_body_fields=[r"^card_number$"]`) or turn capture off entirely.
